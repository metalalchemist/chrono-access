## Cómo registrar el siguiente trabajo

1. Crea un documento numerado por ampliación, con lo que cambió, archivos y datos
   verificados, pruebas, evidencia nativa, límites, activación y reversión.
2. Enlaza el código y los registros de prueba que existan. Distingue pruebas
   sintéticas, ejecución real del motor y valoración del usuario con NVDA.
3. Actualiza el enlace «Último trabajo funcional» al comienzo de este índice.
4. Sustituye el resumen de `continuar chrono.md` por el último estado: enlace al
   documento nuevo, qué quedó pendiente y siguiente paso. No vuelvas a acumular
   allí todas las entregas anteriores.
